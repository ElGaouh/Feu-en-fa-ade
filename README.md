# Feu en façade

Vignettes d'incendie (fumée, flammes, victimes) à poser sur les fenêtres d'un bâtiment réel, pour des mises en situation de sapeurs-pompiers.

- **Tablette / ordinateur** : posez les vignettes sur une photo du bâtiment, réglez-les, faites évoluer la scène depuis le pupitre.
- **Meta Quest 3 / Chrome Android** : bouton « Entrer en réalité augmentée » (WebXR passthrough). Gâchette pour prendre et poser une vignette, joystick ↕ pour la distance, ↔ pour la taille.
- **Liaison** : « Relier tablette et masque » crée un code à 4 chiffres côté opérateur, à saisir dans le masque.

Tout tient dans `index.html` (Three.js chargé depuis jsDelivr).
